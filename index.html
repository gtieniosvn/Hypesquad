❓ FAQ

Có bị Discord ban không?

Nếu dùng đúng cách (1-2 lần/ngày, token chính chủ) → KHÔNG. Spam hoặc dùng token lạ → CÓ THỂ.

Token có bị lộ không?

KHÔNG. Token chỉ lưu trong localStorage máy bạn, gọi thẳng API Discord.

Đổi xong bao lâu thấy huy hiệu?

Ngay lập tức. Refresh Discord (Ctrl+R) là thấy.

❓ Tại sao cần Token?

Token Discord là "chìa khóa" để gọi API thay mặt bạn.

Bot không thể đổi HypeSquad vì Discord chặn IP máy chủ.
Web tool gọi API từ chính trình duyệt của bạn → không bị chặn.

Token không gửi đi đâu, chỉ lưu trong localStorage máy bạn.
