# ⚡ HypeSquad Switcher Web

Công cụ đổi huy hiệu HypeSquad Discord trực tiếp trên trình duyệt.

## 🚀 Tính năng

- Đổi HypeSquad: Bravery, Brilliance, Balance
- Rời HypeSquad
- 100% Client-side - Token không rời máy
- Gọi thẳng API Discord - Không qua server trung gian
- Mobile responsive
- Dark theme
